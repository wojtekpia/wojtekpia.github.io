Privacy policy

Last updated October 20, 2026

In short: this is a personal app with one user. It reads and controls my own Nest thermostats from my own Home Assistant server. It collects nothing from anyone else, shares nothing with anyone, and stores nothing outside my home.

What this app is

This app connects a Home Assistant server that I run in my home to the Google Nest thermostats in my home. It uses Google’s Device Access API and Google sign-in (OAuth). It is a private project for my own household, not a service offered to the public.

What data the app accesses

When I approve access with my Google account, the app can access data about my Nest thermostats through the Device Access API:

  • Current temperature and humidity readings
  • Heating and cooling mode, target temperatures, and whether the system is currently running
  • Thermostat names, rooms, and connection status
  • Change events for the above, delivered through a Google Cloud Pub/Sub subscription in my own Google Cloud project

The app does not access my email, contacts, files, location history, or any other Google data.

How the data is used

The data is used only to show thermostat status in my Home Assistant dashboard and to run my own home automations, such as setting a heating or cooling mode or a target temperature. It is not used for advertising, profiling, analytics, research, or any other purpose.

Where the data is stored

Thermostat data and the sign-in credentials (OAuth tokens) that let the app act on my account are kept on the Home Assistant server in my home. Nothing is copied to a third-party service run by me, and there is no external database, analytics tool, or tracking of any kind.

Sharing

I do not sell, rent, share, or disclose this data to anyone. The only parties involved are Google, which provides the thermostats and the API, and the Home Assistant software running on my own server.

Retention and deletion

Data stays on my Home Assistant server only as long as I keep the integration set up. I can stop access at any time by removing the integration from Home Assistant, or by revoking this app’s access in my Google Account at myaccount.google.com/permissions. Revoking access stops the app from reading or controlling the thermostats immediately.

Google API Services User Data Policy

This app’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Children

This app is not directed to children and does not knowingly collect information from them.

Changes to this policy

If this policy changes, I will update this page and the date at the top.
